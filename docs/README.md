# docs/

## Why this folder exists
Documentation that's too detailed for the main README but should live next to the code, so it's reviewed and
updated in the same commits as the code it describes.

## Files

| Path | What it is | Why it exists |
|---|---|---|
| `architecture.md` | Mermaid diagrams (components, agent graph, escalation sequence, evaluation) and key design decisions with their reasons | Gives reviewers the big picture and the "why" behind each choice. The agent graph can be regenerated from the code, so it can be checked against it |
| [`screenshots/`](screenshots/) | UI screenshots for the README | Shows the working product to someone who hasn't run it |
