# Software Installation & Licence Requests

## Pre-approved software (install yourself)
Open the **NovaTech Software Center** app (Windows) or **Self Service** app (macOS) to install pre-approved tools without a ticket. These include Google Chrome, Firefox, Zoom, Slack, VS Code, Postman, Docker Desktop, Python, Node.js, 7-Zip, Notepad++, and Microsoft Office.

## Requesting licensed or non-listed software
1. Open the IT Service Catalog at https://it.novatech.com/catalog and choose **Software Request**.
2. Enter the software name, version, business justification and whether you need a paid licence.
3. Your manager approves the request in the catalog.
4. For paid licences above $1,000 per year, the department head also approves.
5. IT Security reviews new, never-before-used software for licence terms and data access (up to 5 working days).

Standard turnaround: 2 working days for software already licensed by NovaTech, up to 7 working days for new software.

## Commonly licensed tools
- **Figma, Miro, Adobe Creative Cloud**: design and product teams; others need manager justification.
- **JetBrains IDEs**: available to all engineers on request.
- **Tableau Creator**: limited seats; Analytics team owns allocation.

## Admin rights
Local administrator rights are not granted by default. Engineers can request temporary admin rights for 24 hours through the catalog item **Temporary Admin Access**; it is approved automatically for the Engineering department and logged for audit.

## Prohibited software
Torrent clients, unapproved VPNs or proxies, cracked software, and personal cloud-sync tools (e.g. personal Dropbox) are prohibited on company devices.
