# kb/it/

## Why this folder exists
IT policies, answered by the **IT specialist** (`smartdesk/agent/it.py`). The folder name sets the domain of every chunk inside it, so retrieval can filter to the right specialist.

## Files

| File | Policy | Why it's in the KB |
|---|---|---|
| `password_reset.md` | Password Reset & Account Lockout | The most common IT question; covers the employee-ID format and lockout rules |
| `vpn.md` | VPN Setup & Troubleshooting | Remote access steps per OS, and the personal-device rule |
| `mfa.md` | Multi-Factor Authentication (MFA) | Okta Verify setup and who needs a hardware security key |
| `software_requests.md` | Software Installation & Licence Requests | How to request licences, and prohibited software |
| `wifi_guest.md` | Office Wi-Fi & Guest Wi-Fi Access | Employee and visitor network access |
| `email_mobile.md` | Email on Mobile Devices | Approved mail apps and mobile security rules |
| `laptop_policy.md` | Laptop & Device Policy | Refresh cycle, loaners, damage, loss and theft |
