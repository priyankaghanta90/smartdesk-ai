# kb/hr/

## Why this folder exists
HR policies, answered by the **HR specialist** (`smartdesk/agent/hr.py`). The folder name sets the domain of every chunk inside it, so retrieval can filter to the right specialist.

## Files

| File | Policy | Why it's in the KB |
|---|---|---|
| `leave_policy.md` | Leave Policy | PTO, sick and safe time, holidays: the most frequent HR questions |
| `wfh.md` | Work-From-Home (Hybrid) Policy | Office days and remote-work rules |
| `reimbursement.md` | Expense Reimbursement Policy | Travel, hotel limits, per diem and claims |
| `code_of_conduct.md` | Code of Conduct | Gifts, conflicts of interest and behaviour |
| `anti_harassment.md` | Anti-Harassment & Equal Employment Opportunity Policy | How to report harassment; a sensitive topic that must be answered precisely |
| `performance_review.md` | Performance Review Cycle | Review timing and merit increases |
